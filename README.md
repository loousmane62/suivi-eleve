# Suivi de l'Évolution des Élèves

Ce projet permet de visualiser l'évolution des élèves par matière, à l'aide de graphiques interactifs et d'une exportation en PDF.

## Fonctionnalités
- Saisie des notes par élève et par matière
- Génération de graphiques avec Chart.js
- Exportation des résultats au format PDF
- Interface simple et épurée

## Technologies utilisées
- HTML5 / CSS3
- JavaScript
- [Chart.js](https://www.chartjs.org/)
- [html2canvas](https://html2canvas.hertzen.com/)
- [jsPDF](https://github.com/parallax/jsPDF)

## Déploiement
Le projet peut être hébergé sur GitHub Pages. Pour cela, assurez-vous que le fichier s'appelle `index.html`, puis activez GitHub Pages dans les paramètres du dépôt.
